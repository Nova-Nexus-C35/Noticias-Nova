# Criterio de recursos externos

Los ZIP técnicos revisados no contienen una base editorial de noticias ni fuentes periodísticas verificadas. Por ello, no se importan al repositorio Noticias-Nova.

Noticias Nova utilizará fuentes periodísticas e institucionales verificables, con atribución, fecha, contraste y correcciones editoriales. Los proyectos de software de otros ZIP se mantienen en sus repositorios técnicos correspondientes.
