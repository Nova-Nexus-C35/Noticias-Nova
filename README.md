# Noticias Nova

![Icono oficial de Noticias Nova](assets/branding/noticias-nova-icon.png)

**Noticias Nova** es el proyecto editorial de Nova Nexus.

Principio editorial: informar con rigor, pluralidad, transparencia y verificación.

## Identidad visual

El icono oficial del proyecto se encuentra en `assets/branding/noticias-nova-icon.png`. Utiliza la paleta institucional verde, rojo, azul y plateado.

## Criterios editoriales

Noticias Nova utilizará fuentes periodísticas e institucionales verificables, con atribución, fecha, contraste y correcciones editoriales.
